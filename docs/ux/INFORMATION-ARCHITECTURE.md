# 信息架构 · AI Software Video Studio

## 1. 三层结构

```text
L1 工作室（跨项目）
  ├─ 首页 Dashboard
  ├─ 全部项目
  ├─ 新建项目 Onboarding
  └─ 全局：演示说明 / 主题 / 重置数据

L2 项目（上下文）
  ├─ 知识中心 Knowledge
  ├─ 视频工程 Library
  ├─ 新建视频 Wizard
  └─ 品牌与设置 Brand Kit / Connectors

L3 视频（生产上下文）
  ├─ AI Director
  ├─ Storyboard Studio
  ├─ Video Editor
  ├─ Production Monitor
  └─ Review & Export
```

理由：产品的心智对象是"项目 → 视频 → 镜头"，而不是十个独立功能页。平铺导航会让用户丢失上下文，也无法解释数据如何流转。

## 2. 路由表

| 路由 | 页面 | 主要任务 | 关键出口 |
|---|---|---|---|
| `/` | Dashboard | 知道现在做什么，继续最近工作 | 项目、视频、待办、快速创建 |
| `/projects` | 项目总览 | 浏览 / 搜索 / 进入项目 | 项目、新建 |
| `/onboarding` | 新建项目向导 | 4 种接入方式完成项目初始化 | Knowledge Center |
| `/projects/:projectId/knowledge` | Knowledge Center | 判断 AI 是否理解正确并纠正 | 创建视频、重新验证 |
| `/projects/:projectId/videos` | Video Library | 查看项目下所有视频工程与状态 | 各阶段、创建视频 |
| `/projects/:projectId/videos/new` | Video Creation Wizard | 选择模式、内容、风格，生成策划 | Director |
| `/projects/:projectId/settings` | Brand & Settings | 品牌、默认值、连接器、重置数据 | 返回项目 |
| `/videos/:videoId/director` | AI Director | 协作修改 Brief / 卖点 / 脚本 / 分镜 | Storyboard |
| `/videos/:videoId/storyboard` | Storyboard Studio | 逐镜编辑、排序、证据、时长 | Editor / Production |
| `/videos/:videoId/editor` | Video Editor | 时间驱动预览与精修 | Production |
| `/videos/:videoId/production` | Production Monitor | 启动 / 观察 / 控制模拟生产 | Review |
| `/videos/:videoId/review` | Review & Export | 事实、字幕、隐私检查与导出 | Library / 导出结果 |

所有视频路由通过视频归属项目自动恢复项目上下文。不存在的 ID 显示可操作的 NotFound，而不是空白页。

## 3. 全局导航

### 3.1 侧边栏（可折叠 240px / 64px）

```text
[Lumen Analytics ▾]          项目切换
工作室
  ◦ 首页
  ◦ 全部项目
当前项目
  ◦ 知识中心        功能 / 证据 / 待确认
  ◦ 视频工程        2 个工程
  ◦ 品牌与设置
底部
  ◦ 演示数据 & 能力说明
  ◦ 主题切换
  ◦ 用户（Demo）
```

- 项目导航仅在项目上下文出现；在视频工作区时高亮"视频工程"。
- 项目切换器展示"Demo 数据"标记，避免误以为是真实组织。
- 没有搜索框和通知中心等未实现入口；需要时以真实功能出现，不用死按钮占位。

### 3.2 顶栏

- 面包屑：工作室 / Lumen Analytics / 视频工程 / Director。
- 视频路由下显示五个阶段步骤条（Director、Storyboard、Editor、Production、Review），当前阶段高亮，阶段状态用点标识。
- 右侧：`演示模式` 徽标（点击打开真实 / 模拟能力说明）、帮助入口。
- 不展示无功能的头像菜单；用户菜单为 Demo 身份说明。

## 4. 页面信息架构

### 4.1 Dashboard

**层级**：优先级从"继续工作"到"待处理"到"全量资产"。

```text
欢迎 + 快速新建视频
[主项目卡：Lumen Analytics]
  知识健康度 / 最近同步 / 最近视频 / 继续编辑
[需要你决定]（右栏）
  待审核视频 / 证据过期 / AI 待确认 / 生产失败
[视频工程] 横排
[项目] 列表（2 个）
[最近生产] + [最近功能更新]（并排，紧凑）
```

不使用统计卡片墙；数字只在有行动含义时出现（如"2 条证据过期"）。

### 4.2 Onboarding（6 步）

1. **项目**：产品名、项目名、一句话描述、网站。
2. **接入方式**：GitHub / 产品网址 / 产品文档 / 组合；模拟连接过程与错误。
3. **知识来源**：选择模拟文档与分支；显示"将导入什么"。
4. **品牌**：Logo 字标、配色预设、视觉风格、字体倾向；实时小预览。
5. **演示环境**：URL、数据重置策略、录制范围；域白名单说明。
6. **初始化**：确定性步骤进度，完成后进入知识中心，并出现"AI 发现了 4 个功能"。

每一步可返回，草稿本地保存；名称 / URL 校验内联提示。

### 4.3 Knowledge Center

- 头部：快照信息（模拟同步时间、提交 SHA、环境）、`重新分析`、`创建视频`。
- 标签页：**功能目录 / 时间线 / 待确认 (n)**。
- 功能目录：左侧过滤（状态、置信度、是否已验证）；右侧功能详情。
  - 详情：摘要、状态、置信度、来源引用、Claims、Evidence、关联 PR / Release、演示入口。
  - 可编辑名称、摘要、状态；修改立即保存并记录"人工修正"。
  - Claim 可"重新验证"（模拟）；stale 阻断发布。
- 时间线：PR / Release 按时间合并，显示类型（功能 / 改进 / 内部），内部改动明确"不建议宣传"。
- 待确认：AI 提出的功能、关联、状态变化建议；接受 / 拒绝 / 查看依据。

### 4.4 Video Creation Wizard

三步 + 摘要，不做长表单：

1. **模式**：4 张卡片（宣传片 / 版本视频 / 功能教程 / 持续内容），说明默认时长、比例与典型用途。
2. **内容**：目标、受众、功能选择（带证据状态与风险提示）、Release（版本视频模式）、时长、比例、语言。
3. **风格**：语气、视觉模板、真实录屏 / 生成视觉开关、CTA、禁用表述（高级折叠）。
4. **确认**：右侧实时摘要（预计分镜数、总时长、证据风险）；生成策划。

默认值：宣传片 45s / 16:9 / 中文；版本视频 30s；教程 60s / 真实录屏开；内容工厂 30s / 9:16 / 生成视觉开。所有默认都可解释。

### 4.5 AI Director

```text
[左：对话与快捷命令] [中：Brief + 卖点] [右：脚本与分镜草稿]
```

- Brief 结构化展示并可点击修改（打开字段编辑）；聊天命令改为真实修改数据。
- 卖点列表带 Claim / 证据状态；移除卖点同步移除分镜。
- 分镜草稿可查看、重生成单个、跳转 Storyboard。
- 每次 AI 操作显示"改动摘要 + 影响 3 个分镜 / 总时长 38s"。
- 底部主行动：`确认脚本，进入分镜`（未解决证据风险时提示但不阻断确认，审核阶段会阻断导出）。

### 4.6 Storyboard Studio

- 左侧：镜头列表（缩略图、顺序、时长、状态），支持拖拽与上下移动。
- 中间：选中镜头大预览 + 旁白 / 字幕编辑。
- 右侧：镜头属性（视觉类型、模板、功能关联、Claim、素材、转场、时长）。
- 顶部：总时长、镜头数、自动保存状态、`在编辑器中打开`、`开始生产`。
- 底部 / 卡片内：审核状态、证据提示。

### 4.7 Video Editor

```text
┌ 左侧 280 ─┬─ 中间预览 ─────────┬ 右侧 300 ┐
│ 场景/素材/模板 │ 画面 + 安全区 + 播放控件 │ 属性     │
├ 底部时间线（全宽）──────────────────────────┤
```

- 左侧分镜列表支持点击定位与拖拽排序；素材替换；模板应用。
- 中间：真实时间驱动预览、播放 / 暂停、逐帧、时间码、比例、品牌色、模拟配音波形、字幕。
- 右侧：当前镜头标题 / 旁白 / 字幕 / 时长 / 模板 / 视觉 / 素材 / 功能证据。
- 底部时间线：按比例的场景块、播放头、点击定位、拖拽播放头、总时长。
- 工具栏：撤销 / 重做 / 保存状态 / 比例 / 预览质量标记。
- 快捷：Space 播放暂停、←/→ 逐帧、Ctrl/Cmd+Z、Shift+Ctrl/Cmd+Z。输入框聚焦时不影响输入。

### 4.8 Production Monitor

- 左：本次运行步骤 DAG（编号、依赖、状态、耗时）。
- 中：运行状态（总进度、当前步骤、模拟日志流、失败原因、操作）。
- 右：运行信息（输入工程、场景数、时长、证据快照、审批 Gate、资源 / 模拟成本）。
- 顶部：场景选择器（标准成功 / 录屏失败后重试 / 等待人工审批），明确"这是可重复的演示场景"。
- 状态：运行中、已暂停、等待审批、失败、已完成、已取消；按钮随状态变化。

### 4.9 Review & Export

- 左侧：预览（只读的编辑器预览，可播放）。
- 中：检查清单（旁白完整性、字幕一致性、Claim 证据、敏感信息、品牌安全区、技术 QA）。
- 右：审核动作（通过 / 退回修改 + 原因）、导出配置、导出任务列表。
- 事实检查失败时，"通过审核"禁用并给出可操作路径；不提供"忽略"。
- 导出：MP4 / WebM 为模拟任务；工程 JSON、字幕 SRT 为真实下载。明确标注。

### 4.10 Brand & Settings

- 品牌：字标、Logo 图形、主色 / 辅色、字体倾向、视觉风格、片头 / 片尾文案；实时预览。
- 默认值：比例、语言、模板。
- 连接器：GitHub / 文档 / 演示环境；模拟状态、最后同步、断开 / 重连、错误提示。
- 数据：重置演示数据（二次确认）、导出全部工程 JSON。
- 界面：主题选择（深色 / 浅色）、动效偏好说明。

## 5. 状态归属

| 状态 | 归属 | 持久化 | 说明 |
|---|---|---|---|
| 领域实体（项目、功能、Claim、视频、运行、导出） | `studio-store` | localStorage | 单一事实源，跨页共享 |
| 编辑撤销 / 重做历史 | `studio-store` 内存 | 否 | 刷新后保留当前结果，不保留历史 |
| 当前播放时间 / 播放中 / 选中镜头 | `ui-store` / 页面本地 | 部分 | 播放时间不持久化；选中镜头保存在页面 |
| 主题、侧栏折叠、演示说明打开 | `ui-store` | localStorage（仅偏好） | 不放领域数据 |
| 引导草稿 | localStorage | 是 | 刷新不丢失 |
| Toast / 临时异步状态 | 页面 / UI Store | 否 | 不进入领域层 |
| 生产运行时钟 | mock 引擎 + store action | 仅运行快照 | 通过定时 tick 推进，不随机 |

## 6. 跨页面同步规则

| 用户操作 | 必须同步到 |
|---|---|
| 修改功能名称 / 摘要 / 状态 | Knowledge 列表、功能详情、后续 Wizard、Director 引用、Review 事实检查 |
| 重新验证 Claim | 功能状态、审核清单、导出资格 |
| 接受 / 拒绝 AI 建议 | 功能目录、待确认计数、Dashboard 待办 |
| 删除 Director 卖点 | Brief、Storyboard 镜头、总时长、Editor 时间线、Production 输入摘要 |
| 修改镜头时长 / 顺序 | Storyboard 总时长、Editor 时间线与预览、Review、生产输入 |
| 修改字幕 / 旁白 | Editor 预览、Review 字幕检查、导出 SRT |
| 修改品牌色 / 模板 | 项目卡、视频缩略图、Editor 预览、Storyboard 缩略图、Review |
| 生产完成 | 视频阶段、Dashboard 最近生产、Review 可用性 |
| 审核退回 | 视频状态、Review 提示、Dashboard 待办 |
| 模拟导出完成 | 视频状态、Library、导出列表、Dashboard 活动 |
| 重置数据 | 全部回到种子状态并刷新 |

## 7. 空 / 加载 / 错误状态

- **空**：新项目无视频 → 引导创建；新项目无知识快照 → 触发模拟分析；无待确认 → 轻松的完成态，而不是空白。
- **加载**：模拟连接、知识同步、Director 思考、生产 tick、导出均有可感知的进行态；按钮进入 loading 并禁用重复提交。
- **错误**：内联错误优先于 Toast；失败的生产运行保留原因、日志与重试入口；模拟连接可失败并允许重试。
- **找不到**：项目 / 视频 ID 不存在 → 说明并返回列表。
- **阻断**：stale claim / 未审核 / 工程修改晚于生产 → 明确显示阻断原因与修复路径。

## 8. 响应式策略

- ≥1440：完整三栏 + 侧栏。
- 1200–1439：缩窄左右栏，编辑器属性面板可折叠。
- 1024–1199：侧栏图标模式；Editor 左右栏变抽屉式（先保证预览与时间线）。
- <1024：页面纵向堆叠，编辑器提示"请在更宽的屏幕进行精修"但仍可预览与基本操作。复杂编辑器以桌面优先，不伪装完整移动端体验。
