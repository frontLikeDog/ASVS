# 设计系统 · AI Software Video Studio

> 气质：专业创作工作室（professional creative studio），不是通用后台，也不是营销落地页。
> 优先级：深色模式打磨优先；浅色模式完整可用但克制。

## 1. 视觉方向

**关键词**：墨黑、暖白、信号色、精密、安静、幕后工作室。

- 背景像一间调过色的剪辑室：深、暖、有层次，不是纯黑大平面。
- 荧光青柠作为"启动 / 确认"信号，只给关键主动作和正在发生的事；不大面积铺色。
- 紫色只代表 AI 语义（AI Director、建议、生成），不与主操作抢注意力。
- 内容画面（视频预览、项目缩略图）允许使用品牌色与更强的色块，工作台 chrome 保持中性，两者形成"工具栏 / 画布"对比。
- 细节：细边框、低对比分层面、极轻颗粒、柔和的顶部光。拒绝大面积渐变、发光文字、玻璃拟态滥觞。

## 2. 色彩令牌

| Token | 深色（默认） | 浅色 | 用途 |
|---|---|---|---|
| `--ink` | `#08090B` | `#F4F2EC` | 应用最底层背景 |
| `--surface` | `#0E1014` | `#FBFAF7` | 面板 / 卡片 |
| `--raised` | `#14171D` | `#FFFFFF` | 抬升面板、输入框 |
| `--overlay` | `#1B1F26` | `#F0EEE8` | 悬浮层、选中底色 |
| `--line` | `rgba(255,255,255,.08)` | `rgba(20,18,14,.10)` | 主边框 |
| `--line-strong` | `rgba(255,255,255,.16)` | `rgba(20,18,14,.20)` | 强调边框、hover |
| `--fg` | `#F1F0EB` | `#1A1916` | 主文字（暖白，非纯白） |
| `--muted` | `#9AA0AA` | `#5F5C54` | 次级文字 |
| `--faint` | `#656B76` | `#8B877D` | 辅助、占位 |
| `--accent` | `#D7F36A` | `#3E5B00`（文本）/ `#CBE95A`（底） | 主操作、进度、聚焦 |
| `--on-accent` | `#12150A` | `#FFFFFF` | 主按钮文字 |
| `--ai` | `#A78BFA` | `#6D4AE0` | AI 语义 |
| `--success` | `#5BD6A2` | `#137A50` | 已验证、成功 |

| `--danger` | `#FF7A7F` | `#B42830` | 失败、阻断、删除 |

语义色均配套 8–12% 透明底用于状态胶囊，避免高饱和实心块。

### 品牌色（内容数据，不是 UI 令牌）

项目 `brand.primary / brand.secondary` 只用于：视频预览画面、项目字标、缩略图、导出封面。工作台按钮始终使用信号青柠，防止每个项目把 UI 染成不同颜色。

### 对比度

正文对比度 ≥ 4.5:1；大字与状态点 ≥ 3:1。色彩不作为唯一状态信号，始终搭配文字或图标。

## 3. 字体

| 角色 | 字体 | 用途 |
|---|---|---|
| Display | **Space Grotesk Variable** | 页面标题、视频标题、数字/时间码的强调 |
| Body | **Inter Variable** | 所有 UI 文本、表单、正文 |
| Mono | 系统等宽（ui-monospace / SFMono / Consolas） | 时间码、日志、ID、代码式信息 |

字号 / 行高：

| 名称 | 大小 / 行高 | 用途 |
|---|---|---|
| display-xl | 40 / 44, -0.03em | 首页主标题（少用） |
| display | 30 / 36, -0.02em | 页面标题 |
| title | 20 / 28, -0.01em | 区块标题、卡片标题 |
| body-lg | 15 / 24 | 重要说明 |
| body | 14 / 22 | 默认 |
| small | 13 / 20 | 辅助、表格 |
| micro | 11 / 16, 0.02em | 标签、徽标、时间码 |

标题字重 500–600，不使用 800 大黑体。正文 400，按钮 500。中文使用系统字体回退，字距不做夸张调整。

## 4. 间距、圆角、阴影

- 间距基数 4px：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 56 / 80。
- 页面边距：24（<1280）/ 32（≥1280）；卡片内边距 16–24。
- 圆角：`sm 6px`（输入、小按钮）、`md 10px`（按钮、卡片）、`lg 14px`（面板）、`xl 20px`（大画布 / 对话框）。不使用全圆角按钮。
- 阴影：工作台以边框和层次为主。浮层 `0 24px 60px -20px rgba(0,0,0,.65)`；卡片 hover 只做 1px 边框变化 + 极轻上浮，不做大投影。
- 分隔优先用 1px 线，不滥用卡片嵌套。

## 5. 组件规范

### Button

| 变体 | 外观 | 用途 |
|---|---|---|
| primary | 青柠底 + 黑字 | 每屏最多 1–2 个 |
| secondary | raised 底 + 线框 | 常规操作 |
| ghost | 透明 + hover 面 | 工具、次要 |
| danger | 红字/红底（确认时） | 删除、取消运行 |
| link | 文字 + underline on hover | 内联跳转 |

尺寸：sm 28px / md 34px / lg 40px。图标统一 16px（sm）/ 18px（md）。所有按钮有 hover、active、focus-visible、disabled、loading 状态。纯图标按钮必须有 `aria-label` 与 tooltip。

### 状态胶囊 Badge

`dot + label`。状态映射固定：

- 已核验 / 已完成：绿
- 待验证 / 待审批：琥珀
- 已过期 / 需修改：琥珀（带斜纹或时钟图标区分）
- 失败 / 阻断：红
- 草稿 / 中性：灰
- AI 建议：紫
- 模拟 / Demo：中性描边 + 斜体/虚线感，不使用危险色

### 输入与表单

- Label 在控件上方，13px；必填以文案说明，不用红星堆叠。
- 输入高度 36px，focus 使用青柠 2px 外环 + 边框提亮。
- 错误：字段下方 13px 红字 + 图标；提交失败同时有 summary。
- 帮助文本用 muted，不使用 placeholder 承担说明职责。
- 开关（Switch）用于立即生效的二元设置；选择卡用于重要模式选择。

### 导航

- 侧栏项：32px 高，图标 16px，激活项使用 overlay 底 + 左侧 2px 青柠线（或圆点）。
- 步骤条：编号 / 完成勾选 / 当前高亮 / 未来暗淡；可点击已到达步骤，不可跳过未满足步骤。
- 标签页：下划线式，计数用 micro badge；不使用胶囊标签页做主导航。

### 面板与卡片

- 标准面板：surface + line + 14px 圆角。
- 交互卡片：hover 边框提亮，整卡可点击时有明确 focus ring。
- 编辑器面板不使用圆角堆叠，靠 1px 分隔线形成工具感。
- 空状态：图标 + 一句解释 + 一个主行动，不用插画占位。

### 对话框 / 抽屉

- Radix Dialog：遮罩 `rgba(0,0,0,.6)` + 轻微 blur；面板从中央淡入上移 4px。
- 破坏性操作必须二次确认，按钮文案具体（"删除这个视频工程"而不是"确定"）。
- 不嵌套对话框。复杂表单使用页面或侧抽屉，而不是弹窗套弹窗。
- Esc 关闭、焦点圈定、关闭后焦点归还触发按钮。

### Toast

右下或顶部居中，最多同时 3 条，4 秒自动消失；成功用绿点，失败用红点并保留更久。错误同时提供内联信息，不依赖 Toast 作为唯一反馈。

### 时间线 / 播放器

- 时间码 `00:12.4`，mono 字体。
- 播放头青柠竖线 + 顶部拖拽把手；场景块按真实时长比例，选中描边。
- 播放时不用全局 spinner；状态用播放图标与时间变化表达。
- 模拟预览必须有 `模拟预览` 微标，不冒充最终渲染。

### 聊天 / AI

- AI 消息左侧紫色小标记，用户消息右侧 raised 气泡；不用头像堆叠。
- 每次 AI 操作后附加"变更条"：字段、从 → 到、影响镜头数。
- 正在思考：三点跳动 + "正在修改策划…"，不是无限旋转。
- 不可识别指令：透明说明边界 + 3 个可点击建议，不假装理解。

## 6. 动效

- 页面进入：透明度 0→1 + 位移 8px，180–240ms，ease-out。
- 列表项：最多 stagger 30ms，避免整页瀑布。
- 面板 / 对话框：160–200ms。
- 状态变化（运行步骤、进度、切换镜头）：200–300ms。
- 预览画面内部动效服务于内容（图表、光标、字幕），不做无意义漂浮。
- 遵循 `prefers-reduced-motion`：禁用位移与循环动效，保留状态变化。

## 7. 无障碍

- 所有交互可用键盘完成；可见 focus ring（2px 青柠 + 2px offset）。
- 图标按钮有 `aria-label`；状态点有文本；进度条有 `role="progressbar"` 与 aria 值。
- 对话框 / 抽屉使用 Radix 的焦点管理；禁止自定义 div 模拟。
- 表单错误通过 `aria-describedby` 关联。
- 颜色不作为唯一区分；支持系统缩放至 200% 不丢失关键操作。
- 编辑器快捷键在输入框聚焦时自动让位。

## 8. 内容与语气

- 用产品语言，不用技术状态码：`正在验证功能证据` 而不是 `claim_verification_running`。
- 对模拟能力直说：`模拟连接`、`模拟导出（不生成 MP4）`、`Demo 数据`。
- 不承诺未发生的事：不写"已发布"、"已渲染成功"，除非真实。
- 空状态给下一步，不给歉意："还没有视频工程。从一个已核验的功能开始。"
- 中文为主，必要的产品术语保留英文（Brief、Claim、Storyboard）并在首次出现时解释。

## 9. 响应式与栅格

- 12 列栅格，gutters 16–24；页面 max-width 1440，工作台页面允许全宽。
- 编辑器 / 监控使用固定工具栏 + 弹性画布，不依赖页面滚动完成核心操作。
- 低于 1024：侧栏折叠为图标，编辑器左右面板改为标签切换；保留预览与时间线。
- 触摸目标最小 32×32（桌面），移动布局 40×40。

## 10. 实现约定

- 令牌通过 CSS 变量 + Tailwind 4 `@theme inline` 暴露为 `bg-surface`、`text-muted`、`border-line` 等语义类。
- 组件集中在 `libs/ui`；业务组件不得各自复制按钮 / 面板样式。
- 变体使用 `data-variant` / `data-size` 或清晰的类组合，不用巨型内联样式。
- 任何新颜色先映射到语义 token，不允许页面私有十六进制色值（品牌画布数据除外）。
