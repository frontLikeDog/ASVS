# 用户旅程 · 端到端体验

本文件定义本阶段必须可操作的用户路径、每步的数据变化、异常分支与验收点。

## 1. 主旅程：从项目知识到模拟成片

> 目标用户：Lumen Analytics 的产品负责人，需要为 2.8 版本做一条 30–45 秒更新视频。

| # | 用户动作 | 界面反馈 | 数据变化 | 下一阶段可用数据 |
|---|---|---|---|---|
| 1 | 打开工作室首页 | 看到主项目、待办、最近视频与生产记录 | 无 | 最近视频、待审核、证据过期 |
| 2 | 进入 Lumen Analytics → 知识中心 | 功能目录、证据状态、PR / Release 时间线、待确认建议 | 无 | 功能与 Claim |

| 15 | 打开 Editor，播放预览 | 时间推进，画面切镜，字幕与旁白随镜头变化；模拟配音波形 | 无（读取） | 可编辑 |

## 2. 次旅程：从零创建一个项目

1. 首页 → 新建项目 → 6 步向导。
2. 选择"仅产品网址"，输入任意合法 URL；模拟连接 2 秒成功，生成 3 个基于运行界面的功能候选（置信度较低，标注"仅运行观察"）。
3. 选择"GitHub 项目接入"并模拟连接；显示只读范围、最后同步、Demo 仓库名，明确不访问真实 GitHub。
4. 选择模拟文档（2 份）与分支。
5. 设置品牌色 / 字标 / 风格；右侧预览实时变化。
6. 设置演示环境 URL 与重置策略；域白名单展示。
7. 初始化：知识分析 → 功能抽取 → 证据匹配 → 快照生成，完成后进入知识中心。
8. 新建项目下的功能、默认比例、品牌、连接器状态均可继续使用；视频列表为空并给出创建入口。

**异常**：URL 非法 / 未填产品名 → 内联错误，不进入下一步；模拟连接可失败（网络错误场景），可重试；返回上一步保留全部输入；中途刷新恢复草稿。

## 3. 次旅程：生产失败与恢复

1. 在 Production 选择"录屏失败后重试"场景。
2. 步骤推进到"录制真实操作"约 60% 时失败；状态变红，显示确定性错误（演示环境超时）与日志；后续步骤保持 pending。
3. 用户点击"重试此步骤"；失败步骤重置并成功，后续继续；最终完成。
4. 若选择"取消运行"，状态 cancelled，后续步骤不执行，视频不进入 review。
5. 若选择"等待人工审批"场景，流程在 Gate 2 暂停；用户点击"批准继续"后恢复；未批准前不伪造完成。

## 4. 次旅程：证据过期的阻断

1. 知识中心里"移动端深色模式"功能为 `stale`，其 Claim 证据过期。
2. 用户仍可在向导中选择它（不隐藏真实数据），但卡片显示"证据已过期，发布前需重新验证"。
3. 生成视频后，Review 的事实检查失败，通过按钮禁用，显示对应镜头与证据。
4. 用户点击"去重新验证" → Knowledge 对应 Claim → "重新验证"（模拟）→ Claim verified，生成新 Evidence（Human/Test）。
5. 返回 Review，检查通过，可批准并导出。

**设计意图**：系统不通过隐藏问题来"顺畅"，而是提供清晰的修复闭环。

## 5. 异常与边界体验

| 场景 | 期望体验 |
|---|---|
| 不存在的视频 ID | 说明 + 返回项目视频列表；不白屏 |
| Director 无法识别指令 | 明确"当前模拟导演只支持这些操作"，列出可点击建议；不虚构执行 |
| 删除唯一卖点 | 允许，但提示"视频至少需要一个功能卖点才能生产"，主行动禁用并给出恢复入口 |
| 时长低于 10 秒 | 内联提示最小 10 秒；不静默截断 |
| 镜头少于 2 个 | 生产按钮禁用并说明原因 |
| 审核被退回 | 显示退回原因；Editor 顶部显示"需要修改"；Dashboard 待办更新 |
| 工程在审核后又被修改 | Review 提示"工程已在生产后修改，请重新生产或确认"；模拟导出标明基于旧版本会误导，因此建议重跑 |
| 刷新时正在播放 | 不继续播放；恢复到同一视频与镜头，时间归零或保留选中镜头 |
| 模拟连接失败 | 连接卡显示错误、重试按钮；不阻塞其他来源 |
| 本地存储损坏 / 版本不兼容 | 安全回退到种子数据，并提供重置入口（不崩溃） |

## 6. 数据流转要求（验收重点）

- **功能重命名**：创建视频向导、Director 卖点、Storyboard 证据、Review 事实检查使用同一 Feature 数据。
- **删除卖点**：Director 移除后，Storyboard 对应镜头消失，总时长减少，Editor 时间线更新；若用户想保留需在命令中明确（当前模拟不支持保留，回复会说明）。
- **镜头时长**：修改后 Scene、Storyboard 总时长、Editor 时间线、Review 时长、生产输入摘要一致。
- **字幕**：Editor 修改后预览与 Review / SRT 下载一致。
- **品牌色**：Brand Kit 修改后，项目字标、视频缩略图、Scene 预览、导出封面默认值同步。
- **审核状态**：Review 通过后阶段变 approved，导出按钮启用，Dashboard 待办消失。
- **审批 Gate**：生产运行等待审批时，只有批准后步骤推进；取消则不完成。
- **持久化**：项目、功能、建议、视频、运行、导出、审核、偏好均经 localStorage 恢复；撤销历史不持久化。

## 7. 旅程中的诚实边界

| 能力 | 当前表现 | 不得出现 |
|---|---|---|
| GitHub 接入 | 模拟授权 / 同步 / 错误，显示 Demo 仓库 | 声称已读取真实仓库 |
| 知识分析 | 确定性 fixture / 模板生成，有进度与建议 | 声称调用了真实模型 |
| AI Director | 规则驱动的意图解析，真实修改本地数据 | 声称是真实 LLM 回复 |
| 生产 | 确定性状态机与模拟日志 | 随机伪造成功 / 失败 |
| 录屏 | 展示模拟素材与步骤 | 生成假录像冒充真实操作 |
| 视频预览 | 本地时间驱动的 DOM/CSS 画面 | 声称是渲染后的 MP4 |
| 导出 | MP4/WebM 为模拟任务；JSON/SRT 真实可下载 | 生成损坏 / 伪造的视频文件 |
| 发布 | 不实现 | 自动发布到任何平台 |
